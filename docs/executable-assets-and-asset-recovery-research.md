# 可执行资产与资产回收的分类边界

核验日期：2026-11-08

## 一、结论

“可执行资产”和“资产回收”不能按同一个词直接判为金融，需要看主要解释对象。

1. **可执行资产**不是最高人民法院规范文本中的标准术语。更准确的法律表达通常是“被执行人的财产”“可供执行的财产”或具体财产类型。它描述的是财产在执行程序中的可执行状态，默认归背景层。
2. **资产回收**具有多种含义：
   - 法院执行中通过查封、扣押、冻结、拍卖、变卖等方式实现债权，主要是司法执行和资产处置机制；
   - 银行或金融资产管理公司处置不良贷款、收回现金或非现金资产，属于金融活动；
   - 信用风险中的 `recovery rate`、`loss given default` 等属于金融指标和风险计量；
   - 一般企业的资产处置回款，则要根据卡片主要讨论的是经营管理、司法执行还是融资与现金流。
3. 两者都可能具有详细处置流程或传导链，但流程本身不是分析方法。只有卡片描述的是可重复的估值、回收率测算或损失分布分析程序，才可能归入方法层。

## 二、可执行资产

### 1. 规范用语

最高人民法院 2015 年修订的《最高人民法院关于限制被执行人高消费及有关消费的若干规定》使用“被执行人”“生效法律文书确定的给付义务”和具体消费限制项目，没有使用“可执行资产”这一术语。

来源：[最高人民法院关于修改《最高人民法院关于限制被执行人高消费的若干规定》的决定](https://www.court.gov.cn/fabu/xiangqing/15046.html)

最高人民法院 2021 年关于查封、扣押、冻结财产工作的报道使用“查封、扣押、冻结财产可供执行的价值应与执行标的金额相当”的表述，并说明执行法院要综合考虑财产变价难度、变价后能否覆盖债权、对被执行人和第三人利益的影响。

来源：[山东高院规范查封扣押冻结财产工作](https://www.court.gov.cn/zixun/xiangqing/318541.html)

因此，更严谨的表述是：

- 被执行人的财产；
- 可供执行的财产；
- 可供查封、扣押、冻结的财产；
- 可供变价、拍卖或分配的财产。

“可执行资产”更接近这些法律表达的上位概括或口语表达，不是金融资产类别。

### 2. FinLens 分类

默认分类：`background`。

`cardType`：

- `concept`：解释可供执行财产的范围；
- `mechanism`：解释法院如何查询、控制、变价和分配财产。

交叉：

- 仅说明“银行存款、证券、基金份额、应收账款等可以被执行”，主分类仍是背景；
- 如果卡片主要讨论应收账款、贷款债权、抵押物或金融资产的处置与回收，可考虑 `background + finance`；
- 仅因为财产本身是金融资产，不得把“可执行性”改归金融。

## 三、资产回收

### 1. 司法执行语境

在法院执行语境中，资产回收通常指法院通过查封、扣押、冻结、拍卖、变卖、划拨等方式，实现生效法律文书确定的债权，或者由申请执行人受偿。

主要解释对象是执行程序、财产控制和变价机制，默认归背景层；如果卡片的核心转为债权受偿、抵押物处置、损失回收或回收率，可以交叉金融。

### 2. 银行不良资产语境

在银行、金融资产管理公司或不良贷款处置语境中，资产回收属于金融活动：

- 处置不良贷款；
- 收回现金或非现金资产；
- 核销、重组、转让或证券化；
- 计算回收率和损失。

这类卡片默认归金融层。若解释的是完整处置流程，`cardType` 可以是 `mechanism`，但流程不等于方法。

### 3. 信用风险计量语境

BIS Basel Framework 的信用风险章节将 `PD`、`LGD`、`EAD`、`M` 列为 IRB 方法的风险组件，其中 LGD 与违约后的回收程度直接相关。

来源：[BIS Basel Framework, CRE32: IRB approach: risk components](https://www.bis.org/basel_framework/chapter/CRE/32.htm)

因此：

- `recovery rate`、`loss given default`、`LGD`、`recovery analysis` 在信用风险语境中属于金融术语；
- 如果卡片给出违约数据、回收假设、现金流折现、损失分布和输出指标，则可能构成金融风险计量方法；
- 仅仅描述“先追偿、再处置、最后回收”的过程，仍然是机制，不是方法。

### 4. 企业资产处置语境

企业出售设备、房产、业务或子公司以回收现金，主要可能是：

- 经营与资产管理：背景层；
- 资产剥离、资本回收、现金流改善：金融层；
- 并购或重组交易结构：金融层；
- 具体估值模型：方法层。

## 四、FinLens 分类建议

| 对象 | 主分类 | 交叉 | cardType | 说明 |
|---|---|---|---|---|
| 可执行资产（司法执行） | 背景层 | 视语境 | 概念/机制 | 规范上更宜写“可供执行财产” |
| 可供执行财产 | 背景层 | 视语境 | 概念/机制 | 执行程序中的财产范围与状态 |
| 资产回收（法院执行） | 背景层 | `finance`（讨论债权受偿和资产处置时） | 机制 | 执行与变价程序 |
| 资产回收（银行不良贷款） | 金融术语 | 可交叉背景 | 概念/机制 | 不良资产处置和债权回收 |
| recovery rate / LGD | 金融术语 | 无 | 概念/指标 | 信用风险计量指标 |
| 回收率测算模型 | 方法 | 无 | 方法 | 有假设、输入、折现/模拟步骤、输出和边界 |

## 五、正反例

| 对象 | 分类 | 原因 |
|---|---|---|
| 法院查询被执行人的银行存款并冻结 | 背景层 | 执行措施，不是金融工具 |
| 被执行人名下的证券可以被查封 | 背景层 | 证券是财产类型，执行措施是法律程序 |
| 银行处置不良贷款并计算现金回收率 | 金融术语 | 债权回收和信用损失管理 |
| 回收率模型包含违约损失、回收时点、折现率和情景假设 | 方法 | 可还原的金融风险计量程序 |
| “先查封、再拍卖、最后分配” | 机制 | 有流程，但不是可迁移分析方法 |
| 因为出现“资产”二字就归金融 | 错误 | “资产”是通用词，必须看主要解释对象 |
| 因为出现“回收”二字就归方法 | 错误 | 回收流程不等于分析程序 |

## 六、对分类器的建议

1. 将“可执行资产”“可供执行财产”“被执行人财产”“财产查控”“查封、扣押、冻结、拍卖、变卖”加入背景层执行程序规则。
2. 将“不良资产处置”“不良贷款回收”“债权回收”“recovery rate”“loss given default”“LGD”加入金融术语规则。
3. 不把单独的“资产回收”设为无条件金融强规则；应结合 `bad loan`、`non-performing`、`recovery rate`、`loss given default`、`债权`、`不良资产` 等共同判断。
4. 当卡片主要是“执行流程”“财产处置流程”“风险传导链”时，允许 `cardType=mechanism`，但不自动升级为 `category=method`。
5. 只有当卡片提供完整估值、回收率测算或损失计量程序时，才允许归入方法层。
